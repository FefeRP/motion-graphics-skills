# kit-remotion (secundario, congelado)

Motor anterior del plugin (Remotion 4, React). El motor principal es **HyperFrames** (carpeta `../kit`). Este kit se
mantiene tal cual para lo que aún no está portado: las recreaciones verificadas (`src/motion/recreaciones`: cobre,
cristal, punto, taller, seguimiento, mapa en 3D), la demo de fidelidad y el catálogo de efectos `DemoEfectos2`.
No recibe técnicas nuevas. `npm install` y `node scripts/render.mjs render <Composicion>`.
